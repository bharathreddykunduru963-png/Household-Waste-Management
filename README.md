# Household Waste Segregation Analysis

**Course End Project 4 — Batch 4**
**Section:** G  
**Assigned Roll Numbers:** 25881A05CL, 25881A05CP

## Problem Statement
Analyze household waste by category to identify segregation and recycling patterns.

## Technologies Used
- Python
- SQLite Database
- SQL queries through Python's sqlite3 module

## Project Features
- Record plastic, paper, glass, food waste, and other waste.
- Categorize waste using Python dictionaries.
- Calculate total and category-wise quantities.
- Identify recyclable and non-recyclable waste.
- Validate waste quantity entries.
- Store records in a database.
- Generate monthly reports.
- Identify major waste categories.
- Suggest waste-reduction measures.

## Sample Input
- Household ID: H021
- Plastic: 2.5 kg
- Paper: 3.0 kg
- Glass: 1.5 kg
- Food Waste: 4.0 kg
- Other: 1.0 kg

## Sample Output
- Total Waste: 12.0 kg
- Recyclable Waste: 7.0 kg
- Non-Recyclable Waste: 5.0 kg

## How to Run
1. Install Python.
2. Save the program as `waste_management.py`.
3. Open a terminal in the folder containing the file.
4. Run `python waste_management.py`.
5. Select an option from the menu.

The SQLite database file is created automatically when the program runs.

## Waste Reduction Suggestions
- Reduce single-use plastics.
- Reuse paper and glass containers.
- Compost food waste where possible.
- Segregate waste at the source.
- Send recyclable materials to authorized recyclers.
